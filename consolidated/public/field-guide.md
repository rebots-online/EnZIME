# EnZIME field guide

Carry the sources. Connect the knowledge. Ask a local model to help you apply it.

YOUR LIBRARY
Import a ZIM archive, PDF, EPUB, text/Markdown or media file. Use “Link existing file” for large archives and model weights already in shared storage. Linking fingerprints the original without copying it. The reader will report if its bytes change.

READ AND ANNOTATE
Open an archive, find a title, and follow its internal links. PDFs support page rendering, selectable text, outline navigation, search and text view. Select text, open Companion → Notes, and add your observation. Notes and reading positions are independent of immutable originals.

KNOWLEDGE MESH
Opened source passages contribute small references and genuine relationships to the mesh. Source bodies stay in their archive or document. Search combines lexical relevance and known graph relationships. If a real embedding model is configured, vector relevance joins the same retrieval path. Disposable projection and vector caches are bounded; clearing them preserves your work.

LOCAL INTELLIGENCE
Start a compatible local engine (llama-server, LM Studio or Ollama), then connect its /v1 endpoint in Settings. LFM2.5 is the first-choice model family. Choose a larger compatible model when your device can run it. Model weight quantization and KV-cache compression are different capabilities; TurboQuant support depends on the actual engine build.

Ask in Companion. Retrieved sources appear before the answer, and citation buttons reopen the supporting edition. The assistant reports missing evidence and model failures instead of inventing a simulated answer. Model output still needs your judgment.

CORRECTIONS AND CREATION
Create private drafts and finalize immutable revisions. Correct a passage through a separate overlay: the base source remains unchanged while active retrieval can use your correction. Create ZIM packages from your own work through the same DynDon storage policy.

DYNDON
Choose the storage budget you can afford. Supply a collection manifest with complete reading units, domains/topics, dependency references, exact sizes and SHA-256 checksums. Preview balanced coverage and omissions, then install the selected complete archives. Smaller editions need prepared source manifests or local generation; a ZIM is not made valid by cutting its bytes off.

BACKUP
Export personal metadata in Settings. It contains your private notes, drafts, conversations and reading positions. Transfer original source files separately; a metadata-only restore shows missing originals honestly. Do not publish a personal backup as a public knowledge pack.

OFFLINE REHEARSAL
Import your intended sources and model before disconnecting. Open representative ZIM articles and PDF pages, verify source checksums, add a note, restart EnZIME, and ask a cited question with the local engine. Rehearse the capability you actually need.
